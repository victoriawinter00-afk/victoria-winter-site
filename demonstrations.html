Demonstrations

This page shows working examples of the software and websites I build. It is also where a live look at the e-commerce service is kept, so a prospective client can see how a custom store is built and how it behaves before committing to one.

The link to the store below opens a new tab on your browser.

The store linked below runs in test mode. No real payments are taken and nothing is for sale.

E-Commerce Demonstration Store

The demonstration store is an example of the custom e-commerce service and nothing else. It exists to show how a store works, not to sell anything.

Product catalog: Browse products organized into a catalog, with product pages that present details as a customer would see them.

Cart: Add and remove items and see the running total update.

Checkout flow: Move from the cart through the steps a buyer would take at checkout. Because the store runs in test mode, this uses test card details only and no real payment is taken.

Order recording: See how an order is recorded once the checkout flow completes, which is the foundation a real store would use to manage orders.

This is the storefront side of the Custom E-Commerce Stores service. The catalog sizes, what each band includes, and how payments go live are described on the Web and Software Services page.
